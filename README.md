○ Nom del projecte: E-commerce Full Stack
○ Tecnologies: React, Node.js/Express, MongoDB, Docker ○ Autor (Jan Bertran Sánchez)
○ Com executar el projecte:

  - Inicialitzar Docker en MongoDB:
      Anar a la ruta ~/Escritorio/LanderServeis/backend/docker
      fer les comandes:
      sudo systemctl disable mongod
      sudo systemctl stop mongod
      docker compose up -d
      Comporvar amb docker ps en mongo:latest i mongo-express:latest
